# 列表选择与预览审核

题库、测验集、Agent 工作台共用选择逻辑：

- 常规模式隐藏方形选择框；点击项目打开预览或测验。
- 点击“多选”或 Ctrl / Command 点击项目进入多选模式，选择列滑出。
- Ctrl / Command 点击增加或取消一项；Shift 点击按当前列表顺序连选；Ctrl / Command + Shift 点击追加一个范围。
- Ctrl / Command + A 全选当前列表，Escape 退出多选；输入框中的全选仍按文字编辑处理，预览弹窗不会抢占列表快捷键。
- 多选模式下普通点击切换选择；Tab 聚焦项目后，空格选择，Enter 打开项目或切换选择。
- 切换工作区保留各自的选择；过滤条件变化后，仅保留当前结果中仍存在的项目。选择栏显示已选数，全选框支持部分选中的中间态。

题库支持合并、按所选范围组卷、导出和删除；测验集支持导出和删除；Agent 工作台支持导出与取消未结束任务。批量删除和取消需要在界面确认。部分操作失败时提示成功/失败数量，并保留仍可重试的选择。

## 预览审核

题库默认点击打开预览，编辑入口保留在每行右侧。预览并排显示题干与原图；没有识别文字时直接以原图为主。识别错误、尚未识别和人工核验状态放在独立状态区，不拼接到题干中。

- 通过并保留：先勾选已核对题干、公式、选项和图表，题目更新为 `valuable` / `verified:true`，预览显示审核成功。
- 编辑题目 / 退回修改：进入编辑器；已审核题退回时恢复待审核状态。
- 舍弃此题：排除组卷，保留来源证据。
- 上一题 / 下一题：按打开预览时的当前结果顺序核验。

新图片/PDF 分区候选以空字符串保存尚未识别的题干，识别状态保存在 recognition 字段中。旧版本写入的完整“待识别”占位提示会在列表、编辑器和审核预览中兼容隐藏。空题干候选仍可舍弃，不能通过审核；后端和编辑保存接口均实施该校验。

`POST /api/questions/{id}/review` 接受 `{ "revision": 0, "decision": "approve|return|discard" }`。修订号冲突返回 409，避免审核或覆盖已改变的题目；审核不修改原图、来源或原始 OCR 证据。

验证：33 项 Rust 测试、静态检查，以及实际浏览器的 Ctrl/Shift/全选/退出、原生复选框、范围选择、工作区选择保留、导出、批量取消、部分失败、旧占位隐藏、原图预览、通过/退回/冲突、三主题与窄屏布局检查。
