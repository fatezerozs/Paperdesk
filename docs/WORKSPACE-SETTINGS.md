# 工作区设置与 Agent 审核

侧栏底部「菜单 → 工作区设置」保存识别方式、图片版面、公式增强、Agent 辅助识别及进入题库时的默认状态。设置存放在当前工作区 SQLite 中，重启后仍保留。默认状态在启动或点击侧栏题库时应用；从编辑返回时保留当前筛选。

在线服务地址、密钥继续使用环境变量配置，参见 [部署教程](DEPLOYMENT.md)。外部 OCR 发送授权不会存入设置，仍按次确认。没有接入 worker 时，Agent 任务处于等待状态。

## Agent 目录

默认打开「待采纳」，题干、答案与解析直接渲染 Markdown 和公式。右上角 ⋯ 菜单提供待处理、已采纳和已取消入口；接入说明在独立窗口中打开。多选、Ctrl/Command 点击、Shift 区间选择和全选仅作用于当前目录；隐藏的任务不参与批量操作。

题目预览、编辑页及任务卡片可以再次创建校对任务。任务保存当时的题目修订快照；采纳前不会覆盖已有题干。相同题目、任务类型及修订号的活动任务会复用。执行期间题目发生变化时，采纳将受修订冲突保护。

## 来源删除

在题库的来源菜单中选择「管理来源 → 删除来源」。默认保留题目并解除来源分组，也可明确勾选同时删除关联题目。关联的未完成 Agent 任务取消。删除前核对来源名称与题目列表，若已变化则要求重新打开确认。

来源从管理列表移除，但原件、题目原图和测验快照保留用于历史溯源；这不是磁盘文件清理功能。

## API

- `GET /api/settings`：读取工作区设置。
- `PUT /api/settings`：提交完整设置及 `revision`；冲突返回 409。
- `DELETE /api/papers/{id}`：提交 `expected_name`、`expected_question_ids` 和 `delete_questions`。
- `POST /api/jobs`，`kind: recognition`：识别或重新校对已有题干。

本机写请求仍需 `X-Paperdesk: 1`。Agent 读取与领取协议见 [API](API.md)。
