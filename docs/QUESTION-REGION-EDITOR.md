# 单题识别范围编辑与识别加速

题目预览 → 调整识别范围。直接在原页上拖动选框内部移动、拖动八个手柄缩放，或在空白处重新框选。方向键移动，Shift 加方向键快速移动，Alt 加方向键调整大小。多原页片段可切换后分别保存，不用手动填写像素。

“保存范围”只更新当前题目的裁切与溯源坐标，题目 ID、编号、题干、答案、解析不变；退回待核验，取消未完成的旧 Agent 任务。不会替换同一来源的其他题目。历史题目与旧区域写入 question_region_history，旧裁切文件与原件保留。保存需匹配 revision，冲突时不覆盖新内容。

“保存并重新识别”先保存，再明确授权本题按新范围重新识别；失败时保留当前内容和已保存范围。成功后新题干替换当前题干，原答案解析仍需人工核对。在线 OCR 需到导入界面确认发送授权；多来源题目前仅支持逐片段改范围，重新识别请交给 Agent 对照所有片段。

## API

`POST /api/questions/{id}/region`：`{revision,origin_index,rect:{x,y,width,height}}`，返回新的 Question。裁切不在数据库锁中执行；写入时再次校验修订和原来源，避免识别/编辑并发覆盖。

`POST /api/questions/{id}/recognize` 新增可选 `reprocess:true, expected_revision, formula_enhanced`。重新识别需显式指定当前修订，题目须处于待审核且未核验状态；普通批量识别仍保留人工编辑保护。

## 加速边界

- 服务内部剔除纯白外边缘并保留 16 像素留白，不降低图片分辨率，不改变保存的原图与溯源坐标。
- 对本地 PaddleOCR 已保存且可靠的页面结果，复用完整包含在裁切内的高置信文字行。独立公式只调用现有公式子模型，跳过重复布局和正文识别。低置信度、边界截断、数学正文缺乏公式框或行内公式混合时回退完整流程。此适配依赖固定 PaddleOCR/PaddleX 版本，未知输出不作为成功结果。
- 设置中可关闭 PaddleOCR 数学公式精细识别，使用快速文字模式。它会跳过公式模型，可能降低数学符号与 LaTeX 准确度；数学试卷默认保持精细模式。在线 Mathpix 不受此本地模式开关控制。
- 最近成功输入缓存和既有资源限额仍生效。首次复杂公式推理仍可能较慢，没有通过加线程占满 CPU 或静默换低精度模型来提升速度。
